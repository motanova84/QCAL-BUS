## Epistemic states

`PROPOSED → DEFINED → IMPLEMENTED → FORMAL_PASS → EXPERIMENTAL_PASS → REPRODUCED → REVIEW → ARCHIVED`

`FAIL` is terminal for the current artifact/version until a new evidence chain is produced.

A repository status, CI badge, README statement, DOI, or repetition across repositories **cannot by itself upgrade a claim**.
